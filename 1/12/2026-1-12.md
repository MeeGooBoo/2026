# 1.安装ADB和Python

https://developer.android.com/tools/releases/platform-tools?hl=zh-cn

https://www.python.org

****

# 2.下载Open-AutoGLM

https://github.com/zai-org/Open-AutoGLM

****

# 3.安装依赖

```
pip install -r requirements.txt 
pip install -e .
```

****

# 4.开启手机的开发者模式和USB调试

数据线连接到电脑，改为文件传输，不要选择仅充电，执行命令，检查手机是否连接到电脑

```
adb devices
```

****

# 5.下载并安装ADB Keyboard到手机

https://github.com/senzhk/ADBKeyBoard/releases/download/v2.4-dev/keyboardservice-debug.apk

安装到手机并启用虚拟键盘，执行下述命令

```
adb install keyboardservice-debug.apk
adb shell ime enable com.android.adbkeyboard/.AdbIME
adb shell ime set com.android.adbkeyboard/.AdbIME
```

****

# 6.准备AI模型获取API密钥

你可以选择自行部署模型服务，或使用第三方模型服务商。为了快速演示功能，我这里使用ModelScope(魔搭社区)来部署模型并调用

模型地址：https://modelscope.cn/models/ZhipuAI/AutoGLM-Phone-9B

****

# 7.启动

```
python main.py --base-url https://api-inference.modelscope.cn/v1 --model "ZhipuAI/AutoGLM-Phone-9B" --apikey "你的API密钥" "打开美团搜索附近的火锅店"
```
