# 让 AI 控制 电脑，还能帮你翻墙，帮你下片！ 

让AI全自动的帮我们电脑操作，你会觉得这是科幻电影里的场景，但随着各种科技大厂疯狂发展AI、相互内卷，让AI全自动帮我们完成日常工作将不再是幻想，必然会实现！GitHub已经有非常多的开源项目能够展示AI控制电脑的能力。支持控制苹果系统、window系统！

视频教程：https://youtu.be/nFSnFutwBD4

****

注意：以下操作需要你的电脑具备python环境，没有安装python的可以前往搜索引擎搜索python安装

****

# 1.下载对应系统的TuriX-CUA

项目地址：https://github.com/TurixAI/TuriX-CUA

****

# 2.解压后在目录下执行命令 

```
pip install -r requirements.txt
```

****

# 3.修改配置文件并启动

在 examples/config.json 文件中，可以配置AI模型以及密钥，可以换成自己的模型。比如你有 OpenAI 的，或者你本地跑了AI模型，比如 Qwen3-VL这些，如果不想怎么麻烦的，也可以直接注册Turix官方的API， https://turixapi.io  获取API密钥。你可以修改文件中的task，写上提示词即可！

配置示例：

```
{
  "logging_level": "DEBUG",

  "llm": {
    "provider": "turix",
    "model_name": "turix-large-windows",
    "api_key": "你的API密钥",
    "base_url": "https://turixapi.io/v1" 
  },

  "planner_llm": {
    "provider": "turix",
    "model_name": "qwen3-vl-plus",
    "api_key": "你的API密钥",
    "base_url": "https://turixapi.io/v1" 
  },

  "agent": {
    "task": "你想要它控制你的电脑做什么，需求提示词等可以写在这里",
    "short_memory_len": 5,
    "use_ui": false,
    "max_actions_per_step": 5,
    "max_steps": 100,
    "use_turix": true,
    "save_conversation_path": "llm_interactions.log",
    "save_conversation_path_encoding": "utf-8"
  }
}

```

配置完保存，然后在examples目录执行命令启动

```
python main.py
```
