# 1. 检查电脑或主机是否支持ipv6和网络状态

```

```

# 2. 检查光猫、路由器是否开启了ipv6和防火墙

进入光猫后台和路由器后台的地址一般是你的IPV4地址的第一个IP

怎么进入光猫和路由器的后台？

```
比如 你的电脑IPV4地址是192.168.0.67 ，你可以尝试在浏览器输入 192.168.0.1 或者 192.168.0.2 ，比如 你的电脑IPV4地址是192.168.1.67 ，你可以尝试在浏览器输入 192.168.1.1 或者 192.168.1.2 ，以此类推，不出意外就打开了光猫或路由器的后台，输入账号和密码登录即可。一般家庭的WiFi只有光猫自带的WiFi，有一些家庭可能在光猫的基础上又连接了一个路由器，想要登录光猫的后台就连接光猫的WiFi，想要进入路由器的后台就连接路由器的WiFi。
```

上面的方法都尝试了，还是找不到光猫或路由器的后台地址怎么办？

```
可以尝试访问 默认网关 的IP地址或者查看相关设备背后提供的信息，后台地址一般都写在设备背面。
```

光猫的登录账号和密码是多少？忘记了怎么办？

```
如果不知道光猫后台的账号密码，可以看一下你的光猫背后有没有贴有，一般光猫的后面都是写有默认账户的，就贴在光猫背后，如果还是不知道，可以打电话问一下运营商，或者重置光猫（不建议自己重置光猫，因为有些地区自己重置光猫会有很多问题，最终还是要联系运营商）。
```

路由器的登录账号和密码是多少？忘记了怎么办，怎么重置？

```
如果是路由器的登录密码忘记了，可以自己重置路由器，每个路由器的重置方法都不同，一般都是长按后面的按钮或者用针戳孔10秒，路由器重启后连接，重新设置密码即可。
```
